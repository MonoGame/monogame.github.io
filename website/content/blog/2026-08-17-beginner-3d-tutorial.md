Following on from the huge success of the [Beginner 2D tutorial](https://docs.monogame.net/articles/tutorials/building_2d_games/index.html) and its companion [2D Shader tutorial](https://docs.monogame.net/articles/tutorials/advanced/2d_shaders/index.html), we have started rolling out the **Beginner 3D Tutorial** to the sponsors site for early access (as we did with the initial release of the other tutorials).  Although one thing we are doing differently this time round, is that it is being released periodically over time.

The **first 6 chapters are now live**, with more being added as fast as we can get through the review process with them (which is EXTENSIVE!).

## What to expect

The tutorial builds up everything step by step, starting with the basics of 3D, the math, the camera and much much more, delving into all you need to know to begin your 3D journey using the age old classic of [Star Fox 64](https://www.youtube.com/watch?v=GhQp8le67Xo), a Nintendo 64 classic game, as the basis for the tutorial.

The tutorial includes topics such as:

- Basic 3D rendering using matrices.
- A 3D camera implementation.
- 3D collision detection.
- Creating waves of enemies.
- A 3D particle system.
- Using BasicEffect in 3D.
- Creating effective 2D UI combined with 3D.
- A conversational system for cutscenes.

We will continue to update the tutorial, releasing more chapters, before it goes public.
