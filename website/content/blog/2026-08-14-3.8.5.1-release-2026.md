# The 3.8.5.1 Release

We are pleased to announce the release of MonoGame 3.8.5.1. This is not a major release, it contains mostly bug fixes.

## Improvements & Bug Fixes 

For a full list of all the fixes in this release see https://github.com/MonoGame/MonoGame/pulls?q=is%3Apr+milestone%3A3.8.5.1+is%3Aclosed

* [Deallocating Ringbuffer on GraphicsDevice Disposal in DX12](https://github.com/MonoGame/MonoGame/pull/9442)
* [Cleaning up DX12 CommandListPool on dtor](https://github.com/MonoGame/MonoGame/pull/9447)
* [Fixing lock order violation in background thread in OggStreamer](https://github.com/MonoGame/MonoGame/pull/9461)
* [Fixed bad NormalizedShort2/4 format in Vulkan](https://github.com/MonoGame/MonoGame/pull/9464)
* [added missing state changes in video player](https://github.com/MonoGame/MonoGame/pull/9470)
* [Fix render target retention after dispose](https://github.com/MonoGame/MonoGame/pull/9488)
* [Fix SpriteFont whitespace advance when kerning is disabled](https://github.com/MonoGame/MonoGame/pull/9492)
* [Fix relative OutputDirectory in ContentBuilderProcessorContext](https://github.com/MonoGame/MonoGame/pull/9498)

## What’s Next 

The team is now 100% focused on delivering 3.8.6.
