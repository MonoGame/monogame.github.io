# The 3.8.6.1 Release

We are pleased to announce the release of MonoGame 3.8.6.1. This is not a major release, it contains mostly bug fixes.

## Improvements & Bug Fixes 

For a full list of all the fixes in this release see [3.8.6.1 Milestone](https://github.com/MonoGame/MonoGame/pulls?q=is%3Apr+milestone%3A3.8.6.1+is%3Aclosed)

### Highlights
* [DesktopGL: Fix stale scissor state after Clear
needs-review](https://github.com/MonoGame/MonoGame/pull/9587)
* [Implement loading Assimp library from BaseDirectory](https://github.com/MonoGame/MonoGame/pull/9600)
* [Adding MGG_RenderTarget_WrapNativeHandle Implementation for DesktopGL4](https://github.com/MonoGame/MonoGame/pull/9561)

## [New Getting Started Walkthrough](https://docs.monogame.net/articles/tutorials/getting_started/index.html)

Simon has been hard at work on putting together an updated and friendlier [Getting Started Walkthrough](https://docs.monogame.net/articles/tutorials/getting_started/index.html). 
If you're just getting to know MonoGame, you should start here!

## What’s Next 

The team is now 100% focused on delivering 3.8.7.
